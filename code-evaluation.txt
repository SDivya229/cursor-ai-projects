✅ **Open/Closed Principle (OCP)**:

- Exception handling is extensible

✅ **Liskov Substitution Principle (LSP)**:
- Proper inheritance usage in `EmailServiceException`

✅ **Interface Segregation Principle (ISP)**:

- Minor violation: `EmailService` directly depends on concrete `EmailConfig` rather than an interface

4. **Add Retry Mechanism**:
```java
private CompletableFuture<String> withRetry(Supplier<String> operation, int maxRetries) {
    return CompletableFuture.supplyAsync(() -> {
        Exception lastException = null;
        for (int i = 0; i < maxRetries; i++) {
            try {
                return operation.get();
            } catch (Exception e) {
                lastException = e;
                log.warn("Retry {} failed", i + 1, e);
            }
        }
        throw new EmailServiceException("Failed after " + maxRetries + " retries", lastException);
    }, executorService);
}
```
